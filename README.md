# Supply-chain workspace

This repository hosts the staging area for instruction-tuning release
`REL-2026-W45-09` together with a read-only vendor archive of third-party
release artifacts snapshots for supply-chain review.

Layout:
- `staging/` - the artifact and manifest for the release currently awaiting sign-off
- `vendor-archive/` - candidate Nimbus Data Labs releases and release-card mirrors

The release may not be published until the provenance record has been attached
and the sign-off ticket closed.
